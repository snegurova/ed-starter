---
name: review
description: Use this skill when the user asks for a code review, audit, or quality assessment of TypeScript/JavaScript code — pasted directly or pointed to by a file path. Triggers include "code review", "review this code", "check this code", "do a review", "code audit", "assess this PR", and any request to find bugs or judge code quality.
---

Perform a detailed code review of the following code or the referenced file.

Check for:
1. Correctness of the business logic
2. Error handling and edge cases
3. Security — especially input validation
4. Readability and naming
5. Compliance with TypeScript strict mode

For each issue, provide: severity level (blocker / warning / suggestion), a description of the problem, and a suggested fix.

If the code is good, say so plainly and point out what is done well.
